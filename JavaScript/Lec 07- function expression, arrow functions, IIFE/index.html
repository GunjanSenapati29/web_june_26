Function Expression

- When a function is assigned to a variable it is called as function expression.

Annonymous Function

- When a function having no name that is called as Annonymous Function

- Except function declaration in all other ways we can use Annonymous function to define a function.

Arrow Function

- Arrow function is a shorter way of defining a function by following the syntax

() => {return}
ex:- i) (a, b) => { return a+b }
ii) (a, b) => a + b

IIFE (Immidiately invokable Function Expression)

- When a javascript function runs immidiately after its defination, that is called as IIFE.

i) (function (){ // body })();
ii) (() => { })();
